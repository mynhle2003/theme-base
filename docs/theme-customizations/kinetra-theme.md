## Shared outlined text utility — 2026-10-19

User requested reuse across Virelle and correction of overlapping inner strokes. `assets/virelle.css` now owns `.virelle-text-outline`; `blocks/tab-layout.liquid` attaches it only for Style Outline. The block stylesheet owns selection/hover/focus and mobile layout, not the reusable text drawing. Preserve the existing layout include of `virelle.css` when merging base updates.

The utility paints stroke before fill using `paint-order: stroke fill`. A doubled centered stroke is covered on its inner half with the surface color, approximating Figma's 1px outside stroke rather than painting both halves into glyph interiors. Settings: `--text-outline-width` (visible outer width, default 1px), `--text-outline-color` (default #999), `--text-outline-fill` (default scheme `--background-color`). Use on text or a wrapper to inherit to text descendants. Selected tabs reset stroke width to 0 and fill to currentColor. Forced-colors resets to readable filled text; browsers without paint-order fall back to centered transparent outlined text, and browsers without text stroke keep filled text.

Tab layout overrides the visible outer width to 1.25px on desktop/mobile after the user reported a faint edge. This is optical compensation for browser antialiasing, not the original 1px Figma measurement; keep it local to the tab root and compare visually before further tuning. Other utility consumers retain the 1px default.

Shared consumers audited: Tab layout Style Outline; Countdown timer `outline_text`; Marquee heading `outline`; Collections with background `outline_text`. Countdown attaches the class to values/separators only, retaining the three allowed styles and stale-option protection for inline styles. Opaque countdown units use their actual background for masking; no-background values and separators preserve transparent interiors. Marquee retains its color/opacity and uses the transparent modifier when its section has a background image. Collection titles always overlay media and use `.virelle-text-outline--transparent`; selected titles and product counts reset to filled text. The modifier sets transparent fill plus a centered single-width stroke, preserving photos/video rather than filling glyph interiors with an unrelated solid color. `--text-outline-stroke-width` is the advanced underlying stroke-width override; most consumers use the visible `--text-outline-width` only.

Example: `<h2 class="virelle-text-outline" style="--text-outline-color: #999; --text-outline-width: 1px;">New Arrivals</h2>`. On a custom solid-color surface, set `--text-outline-fill` to that exact background. This surface-color masking technique is not suitable for transparent text over photos/gradients. Preserve dynamic labels and accessibility text; no duplicate text layers or extra JavaScript are needed. Rendered desktop/mobile comparison remains pending because browser use is disabled.

Countdown correction: no-background values and colon separators now mask with `--countdown-outline-surface` (falling back to inherited scheme `--background-color`) rather than automatically forcing transparent centered stroke. The homepage Flash Sale uses no unit backgrounds on a solid scheme-3 surface, so the old transparent fallback was causing the reported overlapping inner strokes. Opaque units still mask with `--countdown-background`. For an actual image/video surface, use the shared transparent modifier explicitly; it retains the centered-stroke limitation. This supersedes the earlier no-background timer note above. Runtime, labels, recurrence and saved settings are unchanged.
